# MagicSquare_xx — Mom Test 질문 10개 프롬프트

## 사용법

- **생성용:** 아래 「질문 생성 프롬프트」를 AI에 붙여 넣어 Mom Test 질문 뱅크를 만들거나 확장
- **실행용:** 「인터뷰 실행 프롬프트」로 ✅ 문항만 골라 1문 1답 인터뷰 진행
- **결과:** `Report/MomTest_Questions10_Report.md` 형식으로 정리

---

## 질문 생성 프롬프트

```
MagicSquare_xx Mom Test용 질문 10개를 만들어줘.
페르소나: 4×4 격자, 빈칸 2개(0), 1~16, 합 34 맞추는 학습자
각 질문에 ✅ Mom Test 준수 / ❌ 위반 표시
❌ 질문은 왜 나쁜지 + ✅로 고친 버전 1줄
카테고리:
- 마지막으로 틀렸을 때
- 검증/확인 비용
- 포기·중단 순간
- 같은 문제를 다시 풀 때
- 다른 사람에게 설명/공유할 때
```

## 인터뷰 실행 프롬프트 (✅ 5문항)

```
MagicSquare_xx Mom Test 인터뷰를 진행해.
너는 스타트업 멘토(Rob Fitzpatrick Mom Test 스타일)야.
나는 [페르소나: 4×4 격자, 빈칸 2개(0), 1~16, 합 34 맞추는 학습자] 역할이야.

규칙:
1. 한 번에 질문 1개만 (아래 ✅ Q1→Q3→Q5→Q7→Q9 순서)
2. 금지: "만들면 좋겠어?", "이 기능 필요해?", 솔루션·클래스명 언급
3. 허용: "마지막으로 ~했을 때", "몇 분 걸렸어?", "뭐 때문에 포기했어?"
4. 내 답이 모호하면 추궁 1개만
5. 내가 솔루션 말하면 "그건 나중" 하고 불편으로 되돌려

✅ Q1부터 시작해. 솔루션 언급 금지.
```

## ✅ 인터뷰용 질문 목록 (복사용)

### Q1 — 마지막으로 틀렸을 때

가장 최근에 4×4 마방진을 **틀린 채로 “맞았다”고 생각했던** 적이 언제예요? 그때 **무엇을 검증하지 않았는지** 한 가지만 말해 주세요.

### Q3 — 검증/확인 비용

지난번에 행·열·대각선 합을 **전부 확인**하려고 했을 때, **몇 분** 걸렸어요? 그중 **가장 오래 걸린 확인** 한 가지는 뭐였어요?

### Q5 — 포기·중단 순간

4×4 부분 마방진 문제를 **중간에 그만둔** 가장 최근 경우가 있어요? 있다면 **그 직전 5분** 동안 뭘 하고 있었어요?

### Q7 — 같은 문제를 다시 풀 때

**같은** 4×4 부분 마방진(빈칸 2개)을 **두 번째** 풀었던 적이 있어요? 두 번째엔 **첫 번째와 다르게** 한 행동 한 가지가 뭐였어요?

### Q9 — 설명/공유

이 문제를 **다른 사람에게** 설명해 본 적이 있어요? 있다면 상대가 **처음 헷갈려 한 부분**이 뭐였고, 그때 **당신은 뭐라고 말했어요?

## ❌ → ✅ 교정 참고 (멘토용 · 질문하지 말 것)

| ❌ 나쁜 질문 | ✅ 고친 버전 |
|-------------|-------------|
| 자동 검증 기능 있으면 실수 줄일 수 있을 것 같아요? | 틀렸다는 걸 알기 전까지 행·열·대각선 중 **어디까지** 맞다고 확인했어요? |
| 합 34 UI 있으면 검증 시간 줄어들까요? | **손으로 계산한 줄** vs **건너뛴 줄** 몇 개였어요? |
| 힌트/가이드 있으면 계속할 것 같아요? | 그만두기 직전 **구체적 이유** 한 가지가 뭐였어요? |
| 문제 저장하면 학습에 도움 될까요? | **메모·코드 재사용** vs **처음부터** 다시 시작했어요? |
| SquareValidator 설명하면 이해 쉬울까요? | 설명할 때 **어디부터** 말했고 **몇 분** 걸렸어요? |
