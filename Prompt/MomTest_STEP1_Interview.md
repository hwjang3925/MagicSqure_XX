# MagicSquare_xx STEP 1 — Mom Test 인터뷰 프롬프트

## 사용법

아래 **인터뷰 실행 프롬프트**를 AI 멘토(Cursor 등)에 붙여 넣고, `[페르소나]`만 바꿔 재사용할 수 있습니다.  
인터뷰 종료 후 `Report/MomTest_STEP1_Report.md` 형식으로 워크북을 정리합니다.

---

## 인터뷰 실행 프롬프트

```
MagicSquare_xx STEP 1 — Mom Test 인터뷰를 진행해.
너는 스타트업 멘토(Rob Fitzpatrick Mom Test 스타일)야.
나는 [페르소나: 4×4 부분 마방진을 손으로/코드로 다루는 학습자] 역할이야.

규칙:
1. 한 번에 질문 1개만
2. 금지: "만들면 좋겠어?", "이 기능 필요해?", "TDD 하면 어때?"
3. 허용: "마지막으로 ~했을 때", "그때 몇 분 걸렸어?", "뭐 때문에 포기했어?"
4. 내 답이 모호하면 추궁 1개만
5. 내가 솔루션 말하면 "그건 나중" 하고 불편으로 되돌려

먼저 인터뷰 질문 1번만 해. 솔루션 언급 금지.
```

---

## 권장 질문 흐름 (멘토용 참고)

| 순서 | 질문 유형 | 예시 |
|------|-----------|------|
| 1 | 최근 행동 | "가장 최근에 ~한 날이 언제였어요? 그날 맨 처음 하려던 일 한 가지는?" |
| 2 | 막힌 순간 | "'이건 안 되겠다'고 느낀 순간, 직전 10분 동안 하던 일 한 가지는?" |
| 3 | 심리·인지 | "문제를 알기 전까지, 맞다고 생각했어요, 이상하다고 느꼈어요?" |
| 4 | 빈도 | "비슷한 일, 그 전에도 있었어요?" |
| 5 | 비용 | "그때 몇 분(또는 몇 시간) 썼어요?" |

## 종료 프롬프트

```
지금까지 답변 요약해줘
```

또는 조기 종료:

```
[N]번까지만 하고 종료할 수 있나요?
```

보고서 저장:

```
종료하고 Report 폴더와 Prompt 폴더에 보고서와 프롬프트 저장해주세요
```

## 워크북 출력 템플릿

인터뷰 종료 시 아래 형식으로 정리:

```markdown
## Mom Test 워크북 — MagicSquare_xx (STEP 1 · 종료)

### 페르소나:
(인터뷰이 1인 — 역할·맥락·도구)

### 인터뷰 답변 (과거 사실):
1.
2.
3.

### 표면 문제 (금지 — 솔루션 섞인 문장):
- "..."

### 진짜 문제 (한 문장):
> (솔루션 없이 고통·제약만)
```

## Mom Test 규칙 요약

| 허용 | 금지 |
|------|------|
| 과거 행동 ("지난주 ~했다") | 미래 의견 ("~하면 좋겠다") |
| 구체적 숫자 (20분, 2회) | 가설적 칭찬 ("좋은 아이디어") |
| 실패·포기 경험 | "이 기능 필요해?" |
| 불편·비용·시간 | 솔루션 제안 (앱, TDD, AI 등) |
